You will receive structured data extracted from a website (headings, meta tags, links, images, schema markup, etc.).

Your task:
1. Analyze the website's SEO implementation
2. Identify strengths and weaknesses
3. Provide actionable recommendations
4. Rate the overall SEO quality (0-100)

- Title and meta description optimization
- Heading hierarchy (H1, H2, H3 structure)
- Schema.org markup (JSON-LD)
- Mobile friendliness
- Internal linking strategy
- Image optimization (alt text)

- URL structure
- Canonical tags

Return your analysis in JSON format with the following structure:

  "overall_score": <0-100>,
  "strengths": [
    {"finding": "...", "impact": "high|medium|low"},
    ...
  ],
  "weaknesses": [
    {"finding": "...", "impact": "high|medium|low", "recommendation": "..."},
    ...
  ],
  "missing_elements": [
    {"element": "...", "importance": "critical|high|medium|low", "why": "..."},
    ...
  ],
  "recommendations": [
    {"priority": "high|medium|low", "action": "...", "expected_benefit": "..."},
    ...
  ]
}

Be concise, specific, and data-driven. Don't hallucinate data not provided.
